# Responsive Website

## Task 4 - Make a Website Mobile-Friendly Using CSS Media Queries

This project converts a desktop-style webpage into a mobile-friendly responsive website using CSS media queries.

## Features

- Responsive navigation
- Mobile-friendly layout
- Flexible content sections
- Reduced font sizes on smaller screens
- No horizontal overflow
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- CSS Media Queries
- Chrome DevTools
- VS Code

## Responsive Design

A media query with a maximum width of 768px is used to adjust the layout for mobile devices.

On smaller screens:
- Navigation items are stacked vertically.
- Content boxes are stacked vertically.
- Font sizes are reduced.
- Spacing is adjusted for smaller screens.

## Testing

The website was tested using Chrome DevTools mobile/device view.
